# MAD Practical 2 – Activity Lifecycle and Basic UI

## 📱 Practical Information

**Subject:** Mobile Application Development (MAD)  
**Practical:** 2  
**Topic:** Activity Life Cycle and Basic UI  
**Platform:** Android  
**Language:** Kotlin  
**IDE:** Android Studio

---

## 🎯 Aim

Create an Android application to demonstrate the **Activity Life Cycle** and basic Android UI components.

---

## 📌 Requirements

The application demonstrates:

- TextView
- ConstraintLayout
- Activity Life Cycle
- Toast Message
- Snackbar Message
- Log Message
- Logcat
- Android built-in colors
- TextView properties

---

## 🎨 User Interface

The application displays:

**Hello World**

in the center of the screen.

### TextView Properties

- Text: `Hello World`
- Text Color: Holo Blue
- Text Size: `27sp`
- Text Style: Bold + Italic
- Background Color: Yellow
- Alignment: Center of the Activity
