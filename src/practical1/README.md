# MAD Practical 1 — Kotlin Programs

This folder contains the Kotlin programs completed for **Mobile Application Development (MAD) Practical-1**.

## 📚 Practical 1 — Kotlin Programming

The practical covers basic to intermediate Kotlin programming concepts including:

* Variables and different data types
* Type conversion
* User input and output
* Conditional statements
* `when` expression
* User-defined functions
* Recursion
* Arrays and ArrayList
* Sorting
* Classes and constructors
* Inheritance
* Operator overloading
* Matrix operations

## 🛠️ Technologies Used

* **Language:** Kotlin
* **IDE:** IntelliJ IDEA
* **Course:** Mobile Application Development (MAD)

## ▶️ How to Run

1. Open the project in IntelliJ IDEA.
2. Open any `.kt` file.
3. Find the `main()` function.
4. Click the **Run ▶** button.
5. View the output in the terminal.
